# Установка OMNIA SA — GTA San Andreas 1.01

1. Убедись, что установлен CLEO 4, совместимый с твоим GTA SA PC 1.01. Для CLEO-скриптов также нужен ASI Loader; некоторые сборки CLEO включают его.
2. Сначала запусти игру без OMNIA и убедись, что CLEO загружается.
3. Скачай ZIP-артефакт `OMNIA-SA-1.01` из GitHub Actions.
4. Распакуй архив. Внутри будет папка `cleo`.
5. Скопируй папку `cleo` в корневую папку GTA San Andreas (туда, где находится `gta_sa.exe`). Если Windows спросит об объединении папок, соглашайся; существующие файлы не перезаписывай без резервной копии.
6. Запусти игру. Нажми F10, чтобы показать тестовую панель, и F10 ещё раз, чтобы скрыть её.

Если папки `cleo` нет, не создавай её вместо установки библиотеки: сначала установи совместимую CLEO 4.

Удаление OMNIA: удали только файл `cleo/OMNIA_MENU.cs`.
